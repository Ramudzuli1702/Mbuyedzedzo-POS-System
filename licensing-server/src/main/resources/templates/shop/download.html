Setting up for the first time

  1. Run the installer for your edition and follow the prompts — it sets up its own database, no separate MySQL install needed.
  2. On first launch you'll be asked to activate: paste in a licence key from your purchase, or start the free 30-day trial straight from that screen if you just want to try it first.
  3. The first account you create becomes the admin account for that till.
  4. To add the phone scanner, install the APK on an Android phone on the same Wi-Fi as the till, then scan the QR code shown under the WiFi status button in the app.
