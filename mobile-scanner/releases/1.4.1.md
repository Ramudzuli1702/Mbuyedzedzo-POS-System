# Scanner 1.4.1

- Receipt details use the app's Material theme, fixing a theme conflict when opening a receipt.
- Receipt navigation passes a saved receipt ID instead of the full serialized receipt, avoiding Android transaction limits for large receipts.
- The stocktaking clipboard now contrasts with its teal background.
- Keeps the existing staff login and receipt storage. The development signing certificate is unchanged for in-place updates.

The APK replaces `Mbuyedzedzo-Scanner.apk` in release `v1.0.0`; its download URL stays the same.
