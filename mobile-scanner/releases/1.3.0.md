# Mbuyedzedzo Scanner 1.3.0

- Product scanning now supports desktop Code 128 labels and retail barcodes. QR mode is reserved for desktop pairing. Leading zeroes and equivalent UPC/EAN forms are handled.
- Receipts save before acknowledgement, replay after reconnect without duplicates, and display the desktop's wrapped items and final total correctly.
- Stocktaking uses existing active staff accounts, pulls an inventory snapshot, saves counts locally, and submits them for Admin/Manager review. Submission leaves stock unchanged. Approval applies all counted corrections atomically; intervening stock movements require a recount. Uncounted products remain unchanged. Review decisions and notes are retained.
- New screens follow the existing teal Material theme, outlined fields and rounded cards.

## Desktop requirement

Install/run the desktop built from this release's source commit. Older published desktop installers do not contain the stocktake approval tab or reliable receipt outbox. The companion database migration runs during desktop database setup. Review counts under **Supervisor Approvals > Stocktakes**. Use both devices on the same trusted local network.

## Verification

Passed: 13 Android unit tests, 41 desktop unit tests and 6 MySQL/socket integration tests. Checks cover Code 128/EAN decoding, receipt parsing/framing, password proofs, local count semantics, desktop framing/validation, and real MySQL/socket workflows for approval, rollback, ownership, login and receipt reconnect delivery. Test databases are isolated from the shop database. The optional interactive integration test was skipped.

The emulator was unresponsive on the build machine, so an emulator UI walkthrough and physical-camera testing remain unverified.
