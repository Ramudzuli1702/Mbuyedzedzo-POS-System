# Mbuyedzedzo companion 1.4.0 and desktop 1.0.6

- General staff sign-in after pairing now covers scans, products, receipts and stocktaking. The desktop independently enforces authentication; reconnects, sign-out and password changes require sign-in again.
- Android receipt history, details, totals and original text use the shared teal/white/slate design. Login, navigation and stocktaking follow the same design, without a second stocktake login form.
- Desktop stocktaking has a distinct checklist icon and a standard white header/card layout.
- Settings includes inventory and stocktake sheet folders. Save As starts there; preferences save in a writable per-user directory and retain existing encrypted configuration values.
- View opens labeled editable product, customer, staff and promo information directly. Product details include the barcode preview and print action. Historical detail displays share the same presentation.

Update desktop and Android together. Desktop installers and the APK replace the existing assets in v1.0.0 with their original filenames, preserving website links. No new Android release is needed.

The desktop builds also include the earlier MySQL first-run setup fix: server provisioning is handled by the application, while users choose the server password and approve Windows elevation when required. New server installation requires internet access.
