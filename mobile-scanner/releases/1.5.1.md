# Scanner 1.5.1

Use this version with the updated desktop's secure scanner connection. The older IP-only Android protocol cannot connect to a TLS desktop and does not recognize its pairing QR.

- Scan the desktop's current QR, or paste its full copied connection code. The pairing code includes the desktop's certificate identity.
- Check desktop capabilities before opening staff login. Pairing failures show an explanation instead of repeatedly reopening login.
- Keep the login screen open through a network interruption; retry temporary failures and stop retries for incompatible pairing identities.
- Allow two minutes to enter staff credentials on the desktop connection, replacing the old 30-second limit.

Local APK: `release-artifacts-new/scanner-connection-fix/Mbuyedzedzo-Scanner-1.5.1-debug.apk`. Its checksum and signing-certificate fingerprint are in the adjacent `artifact.json`. This development-signed build replaced `Mbuyedzedzo-Scanner.apk` on the existing GitHub v1.0.0 release on 20 October 2026, keeping the website's download URL. The desktop installers on that release remain 1.0.8 and predate secure pairing; use the matching updated desktop build.

Install the APK over the existing app, restart the desktop using the updated source, then pair again. Existing saved bare IP addresses are not valid secure pairing codes.

Verification: 18 Android JVM tests, Android lint/debug assembly, 62 desktop unit tests and 26 disposable-MySQL integration tests passed. Two optional UI/device integration tests were skipped. The new TLS integration test pins a temporary desktop certificate, waits 31 seconds before login, authenticates an existing staff account and sends a barcode. No physical Android device was attached, so phone UI verification remains outstanding.
