# Desktop 1.0.9 and Scanner 1.5.1

Release preparation: 24 October 2026. Existing v1.0.0 download names are retained for website compatibility; the release description identifies the current source commit and artifact versions. The original v1.0.0 tag/source archives are not moved.

## Desktop

- Secure phone pairing over TLS with certificate-fingerprint verification and shared staff login. Update both desktop and phone, then scan the current desktop connection QR; old bare-IP pairing cannot verify the secure desktop.
- Stocktake/financial/session reviews use short-lived single-use supervisor keys. Generate them from Sessions → Auth Key after confirming the supervisor's staff password.
- Transactional checkout, paid-price refunds, preserved sale costs, stock-version conflict detection and edition-scoped database credentials.
- Retail promotions: temporary prices, percentage/rand discounts, quantity deals, buy/get rewards and fixed bundles with selected alternatives. Excel imports create drafts; publishing/disabling requires a manager key. Test baskets preview the best qualifying non-overlapping offers.
- Shared detail forms, report styling, transparent sidebar branding and application icons. Barcode labels save locally as PNG.
- Staff/manager instructions, troubleshooting, code architecture and a generated 25-table database reference.

## MySQL setup verification

The installer bundles Oracle's `mysql-installer-web-community-8.0.46.0.msi`, rather than a renamed server MSI. The helper validates the Oracle signature and MSI product identity before running it. It uses the documented console product selector to install/configure MySQL Server, handles prerequisites and starts the service automatically. New installations still need internet and Windows administrator approval.

The native setup check passed on a disposable, non-default-port MySQL instance, including a chosen password containing punctuation and Unicode. Existing-server credentials and interrupted-setup recovery are covered by the desktop unit suite. The check does not reinstall the shop's MySQL service.

Packaging verification checks that each clean build contains the exact helper, correct edition, pinned web MSI and a single current launcher JAR. Each bundled runtime is exercised for barcode generation, extended charsets, Windows secret protection, TLS identity creation, promotional pricing and workbook export.

A complete first installation/UAC/reboot walkthrough on a clean Windows VM and physical phone/camera acceptance remain separate manual checks; automated/native/runtime checks do not claim to replace them.

## Android

Scanner 1.5.1 (version code 8) uses the existing sideload signing certificate, application ID `com.pos.scanner` and Android 7.0 minimum. It supports secure connection QR parsing, authenticated scanning, account-scoped encrypted receipts and stocktaking. The sideload APK is development-signed, not Play Store signed.
